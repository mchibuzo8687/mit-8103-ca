## Case Study

**Organisation:** CareLink Clinic  
**Type:** Multi-branch outpatient clinic management system  

CareLink Clinic is a simulated private outpatient healthcare network with multiple branches. The database supports patient registration, doctor scheduling, appointment booking, clinical encounters, prescriptions, laboratory orders/results, and billing.

| Aspect | Detail |
|--------|--------|
| Users | Receptionists, doctors, nurses, laboratory staff, pharmacists, branch managers, patients (self-service views) |
| Major data | Patients, staff, branches, appointments, encounters, prescriptions, lab tests, payments |
| Key operations | Register patient, book/cancel appointment, record diagnosis, prescribe medication, order lab tests, process payment, retrieve patient history |
